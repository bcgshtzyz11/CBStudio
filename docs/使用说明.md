# CBStudio 台架工作台

一个本地网页版的 CAN / 继电器台架工作台：手动设状态、拖拽排序“断电仪表盘”、跑剧本、
失败自动保全现场、抓屏与画面数值比对。

后端是 Python 标准库 HTTP + SSE，前端是纯 HTML/JS，**不需要编译、不需要联网**。

---

## 一、开包即用（真实台架）

1. **双击 `CBStudio.exe`**（免装 Python；Windows 10/11 自带运行库即可）
2. 浏览器打开 <http://127.0.0.1:8777/>

> 只需要 CAN 收发时，才需要本机有一个 **32 位 Python**（见下面「CAN 需要额外准备」）；
> 继电器、串口、剧本、抓屏这些功能跟 Python 无关，装了 exe 就能用。

想改代码跑源码时才需要 Python 3.10+：

```bat
pip install -r requirements.txt
run_studio.bat        :: 参数与 CBStudio.exe 完全一样
```

默认配置已经按台架接好，直接可用（口/路径留空 = 自动识别）：

| 项 | 默认值 | 说明 |
|---|---|---|
| 继电器（LCUS-4） | **自动识别**（优先 CH340，可在设置里填死） | 主电/ACC/IG/备用 四路 |
| DUT 调试串口 | **自动识别**（优先 Prolific/FTDI/CP210x） | MCU 日志 |
| adb | **自动识别**（PATH / 随包 `platform-tools` / Android SDK） | 抓 SOC 日志、抓屏 |
| CAN | ZLG USBCANFD-200U，CH0=ICAN CH1=PCAN，500k | 需要 32 位 Python（自动找）+ 随包 `sdk/zlgcan` |
| 报文清单 | 随包 `can_matrix_manifest.json` | 相对工作台目录解析，随机发送用 |

串口/继电器口和你机器不一样时，在界面 **设置** 页改完保存即可（串口是下拉选，保存即重连）。

### CAN 需要额外准备

随机发送走 32 位子进程，只需要一个 **32 位 Python**：`can.python` 留空时程序会自动找
（`py -3.8-32` → 本机 `Python3*-32` / ZLG ZCANPRO 自带的 `python38` → PATH 上的 `python`），
按子进程回报的位数筛掉 64 位。想固定就填绝对路径，或设环境变量 `CBSTUDIO_PYTHON`。

`zlgcan` 驱动已随包放在 `sdk/zlgcan/`，**不需要 pip 安装**，也不用另下 ZLG 的 Python 包。

没有 CAN 设备也能正常用其它功能（继电器、串口、剧本、抓屏）。

---

## 二、没有硬件也想看界面

双击 **`CBStudio.exe --sim`**（快捷方式里加参数，或在 cmd 里敲）；源码版用 `run_sim.bat`。
不碰继电器/CAN/串口/adb，数据全模拟，可以完整走一遍剧本、事故保全、抓屏预览。

## 三、目录说明

```
CBStudio.exe              exe 入口（双击即用，免装 Python）
_internal/                exe 的 Python 运行时 —— 必须跟着 exe 一起拷，单独拿 exe 起不来
run_studio.bat            源码启动（开发用；参数与 exe 一致）
run_sim.bat               仿真模式快捷方式
src/                      源码
  app.py                    入口（--sim / --dry-run / --no-browser / --port）
  studio/                   后端（通道、探针、剧本运行器、SSE、事故保全、抓屏比对）
  can_engine.py             32 位 CAN 收发子进程
  can_pack.py               CAN 报文位打包（can_engine.py 依赖）
  web/                      前端（index.html + css + js，无构建）—— 改完刷新即可，不用重新打包
scripts/                  打包脚本
  build_exe.bat             重新打包 exe（需要 Python + PyInstaller，产物落在工程根目录）
  cbstudio.spec             打包配置（单目录 / 保留控制台 / 前端外置）
sdk/zlgcan/               ZLG 驱动：ctypes 绑定 + dll + kerneldlls
scenarios/                剧本（JSON，可拖动排序）
can_matrix_manifest.json  CAN 报文清单
config.json               配置（首次启动生成）
requirements.txt          源码版主进程依赖（pyserial / openpyxl）
data/                     运行时生成：日志、运行记录、事故目录、抓屏（本包不含）
docs/                     本说明 + 界面截图（docs/screenshots/，README 见工程根）
```

**发布就是拷整个文件夹**：exe 靠「自己的所在目录」找 `src/web src/can_engine.py src/can_pack.py
scenarios config.json sdk`，所以不能只发一个 exe，也不能把 exe 单独挪到别处。

## 四、注意

- 默认只监听 `127.0.0.1`；要给局域网其他人访问，启动时加 `--host 0.0.0.0`（自行评估风险）。
- 首次运行会自动创建 `data/`（exe 放在只读目录，如 `Program Files`，会建不了）。
- 拿不到硬件的表现：继电器/串口显示红色故障、`adb=offline`，但**界面和其它功能照常可用**。
- **继电器识别不到**：先确认 CH340 继电器没被别的程序（串口助手/ZCANPRO/另一个工作台）占着；
  DUT 串口自动识别不会抢继电器口，继电器启动时若打不开，改完设置点保存会重试连接。
- **杀毒/公司策略拦截 exe**：PyInstaller 打的包没签名，个别终端会拦。加白名单即可；
  要换回脚本方式，`run_studio.bat` 仍然可用，功能一致。

完整功能说明见 `README.md`。
